🔄 Synchronisatie via GitHub

Sla de planning op in je GitHub-repository, zodat je op elk apparaat (ook buitenshuis) dezelfde gegevens ziet. De gegevens komen op een aparte branch, zodat ze niet op de openbare Pages-site belanden. Maak op GitHub een fine-grained token aan (Settings → Developer settings → Personal access tokens) met alleen Contents: Read & write voor deze ene repository.
